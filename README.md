# Shaik Mansoor Sadhik | Portfolio

A modern, responsive developer portfolio showcasing my profile, technical skills, experience, projects, and contact information. Built with React, Vite, Tailwind CSS, and shadcn/ui.

## ✨ Features

- **Home:** Introduction and developer profile
- **About:** Background and technical skills
- **Experience:** Professional experience and development journey
- **Projects:** Showcase of selected projects
- **Project Pages:** Dedicated pages for projects such as Smart Assistive Chair, E-Commerce Platform, and Task Manager
- **Blog:** Section for technical articles and learning resources
- **Contact:** Contact form and communication options
- **Resume Download:** Option to download my resume
- **Responsive Design:** Layout designed for different screen sizes
- **Interactive UI:** Animations, hover effects, and reusable components

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript
- **Styling:** Tailwind CSS
- **UI Components:** shadcn/ui and Radix UI
- **Build Tool:** Vite
- **Routing:** React Router
- **Icons:** Lucide React
- **Backend Integration:** Supabase
- **Version Control:** Git and GitHub

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Mansoorsk12/Mansoor_Portfolio.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Mansoor_Portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 📦 Build for Production

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

Run the lint checks:

```bash
npm run lint
```
